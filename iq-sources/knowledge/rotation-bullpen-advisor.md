### Ace Option Management

**Best Practices (from Community Research):**

**After High Pitch Count Game (120+):**
1. Temporarily turn OFF "Use Ace" checkbox
2. Give Randy Johnson 4 days rest
3. Turn "Use Ace" back ON after that start

**Why This Matters:**
- Moving 5-day endurance window creates overlap
- High pitch count + short rest = earlier fatigue next game
- Even Ex durability pitchers need occasional extra rest

**Monitor:**
- Check Randy Johnson's pitch counts each game
- If 120-130 pitches: Consider 4 days rest
- If 130+ pitches: Definitely give 4 days rest
