## Key Defensive Insights

**Error Rating Impact:**
- Lower ERR = fewer errors = better defense
- CF errors cost most (1.13 runs per error)
- OF errors more costly than IF errors
- Each range band saves ~10 hits, but errors cost runs

**Position Priorities:**
1. **CF Defense** - Most important (errors cost 1.13 runs each)
2. **SS Defense** - Critical for double plays
3. **3B Defense** - Hot corner importance
4. **1B Defense** - Errors at 1B cost 0.79 runs each

**Value Considerations:**
- Iron injury ratings add value (durability)
- Multi-position players add flexibility
- Balance offense vs. defense based on budget
- Consider park factors (defense matters in all parks equally)
